# Paw Hand

悠哉字体（[lxgw/yozai-font](https://github.com/lxgw/yozai-font) v0.868）的修改版：只保留 GB2312 的 6763 个常用汉字、界面文案用到的字和常用标点，以缩小安装包。按 SIL Open Font License 1.1 的要求，修改版不使用保留字体名，改名为 Paw Hand。许可证见 [OFL.txt](OFL.txt)。

A modified version of Yozai (lxgw/yozai-font v0.868), subset to the 6,763 GB2312 hanzi, the characters used in the UI, and common punctuation to keep the app small. Renamed to Paw Hand because the SIL Open Font License 1.1 reserves the original names for unmodified versions. License: [OFL.txt](OFL.txt).
