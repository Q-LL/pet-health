## 待开发功能

按数据可恢复性和日常使用价值安排后续顺序；这些项目尚未作为可用功能开放。

1. **数据保护**：完整备份 / 恢复及格式校验，覆盖用户数据库、应用照片和相册引用的恢复限制。
2. **就诊整理**：就诊 / 复诊记录、处方原文、通用附件关联，以及可导出的健康摘要。
3. **本地检索与统计**：知识库 FTS5、知识包版本替换和更多数值趋势。
4. **新增能力**：OCR 候选字段确认、GPS 路线与轨迹文件管理；开发前分别明确权限、数据模型和验收范围。

目前体重趋势已经实现，不再列为未完成项。导出与备份入口已从设置移除；数据库中的 `routeFilePath` 字段不代表 GPS 路线已经接入。

## 继续开发的验收要求

- 用户写入只归属真实的当前狗狗；切换档案后不显示上一只狗狗的数据。
- 数据库写入成功后才关闭表单或提示成功，失败时保留输入。
- 普通新增撤销只删除对应新记录；提醒 / 计划关联保存不能被单独撤销破坏状态。
- 日期回看保持本地自然日 `[00:00, 次日 00:00)` 的筛选口径。
- 遛狗结束不依赖后续地点填写，重复结束不生成重复记录。
- 通知或相册权限失败不丢失已经保存的文字记录和提醒数据。
- schema 变更提交新版本快照（`drift_schemas/`），并有逐版本迁移与数据保留测试；README、架构、接口与 UI 文档同步更新。
