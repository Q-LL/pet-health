# UI 重构：主流程落地

更新：2026-10-03。沿用已确认的六张参考画面和森林绿、暖白、杏色风格。

## 页面层级

| 层级 | 入口 | 内容 |
| --- | --- | --- |
| 主导航 | 今天 `/today` | 今日待办、四格快速记录、健康信号、一条最近时光 |
| 主导航 | 时间线 `/timeline` | 健康、护理、遛狗、时光混排；列表 / 日历；分类与日期筛选 |
| 主导航中心 | ＋ | 最近用过、健康、护理、生活三个分组；选择后打开全屏记录表单 |
| 主导航 | 照护 `/care?seg=todo/plans/insight` | 待办、计划、洞察；保留提醒完成、稍后和护理计划执行 |
| 主导航 | 狗狗 `/pet` | 当前档案、切换狗狗、近 90 天体重、洗澡与提醒摘要、健康档案 |
| 二级页面 | 狗狗页右上角 `/settings` | 快速记录配置、相册缓存、本地知识库、隐私说明 |
| 二级页面 | `/memories` | 独立爱宠时光入口；今天和时间线均可进入 |
| 二级页面 | `/records?type=weight/…` | 原有完整记录管理与按类型查看 |
| 二级页面 | `/reminders`、`/care/coverage`、`/care/dynamics` | 提醒管理、护理完成率、健康动态详情 |

底栏保留五格。四个页面各自保留状态，中心 ＋ 是操作入口。二级页面和全屏表单隐藏底栏，返回恢复来源页面；直接打开二级链接时，返回今天。

## 交互与数据

- 今天预览最多三条提醒及两条待处理护理计划，完整任务进入照护；原来的提醒完成、稍后和自动记录规则继续生效。
- 时间线按当前狗狗读取真实数据。列表默认回看七天，可逐次加载更早七天；日历查看选中当天。分类写入路由参数 `type`。
- 写记录先选择类型，再直接进入全屏表单。饮食可沿用上次食物、份量和单位，观察结果仍由用户填写。
- 默认快捷入口为体重、饮食、饮水、更多；已有的三项自定义配置继续生效。
- 表单展示当前狗狗、可调整时间、数值及选项；标题与健康记录类型放在折叠区。保存固定在底部并避让键盘。
- 普通新增健康 / 护理记录保存后提供五秒撤销；编辑和关联提醒 / 护理计划的保存不提供会破坏关联状态的单独撤销。
- 遛狗计时条放在底栏上方，切换四个页面仍可结束。结束先停止计时并保存，之后可选补充地点。
- 时间线对进行中遛狗显示“正在遛狗”，不显示为零分钟的完成记录；该卡片不提供普通编辑入口，结束动作集中在底部计时条。
- 狗狗默认头像使用名字首字，有真实头像时显示照片。体重曲线只使用已有记录；不足两次时显示提示。
- 暂未实现的导出、备份入口从设置移除，避免可见按钮点击无响应。
- 旧 `/home`、`/calendar`、`/pets` 及对应子入口保留重定向，查询参数继续传递。

## 代码结构

- `lib/core/ui`：主题 token、页面容器、卡片、选项组、加载 / 空 / 错误状态与动画。
- `lib/app/app_shell.dart`：五格底栏与全局遛狗条。
- `lib/features/calendar/presentation/timeline_page.dart`：统一时间线；替代旧日历页。
- `lib/features/records/presentation/record_hub_sheet.dart`：记录中心；`RecordEditorFrame` 统一全屏编辑布局。
- `lib/features/reminders/presentation`：提醒编辑器、展示辅助函数和可操作提醒行；首页不再承载整套提醒编辑实现。
- `lib/features/care/presentation/care_todo_body.dart`：照护待办和真实周进度。
- `lib/features/pets/presentation/pet_dashboard.dart`：当前狗狗摘要与真实体重趋势。
