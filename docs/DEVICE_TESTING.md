# 实机测试清单

开发流程：功能先在 Web 上做完、测完，再装到手机上找 Web 测不出来的问题。本文记录**只有实机才能确认**的事项，做新功能时遇到就往这里加，实机测试时逐项过一遍。

测试设备：iPhone（作者），Samsung、Xiaomi（朋友，Android）。

## 平台能力

- [ ] **计划提醒通知**：权限请求、到点弹出、点通知打开 App。（通知还没做，做完再测。）
- [ ] **狗狗头像**：选照片、拍照、裁剪后保存；重启 App 后照片还在；删除档案后照片文件一起清掉。
- [ ] **数据保留**：划掉 App 再打开，记录、计划、设置都还在。
- [ ] **覆盖安装旧版**：v1 和旧版用同一个 Bundle ID。装在旧版上面时能正常进入引导，不会读到旧数据出错。

## 界面与交互

- [ ] **安全区域**：刘海、灵动岛、底部横条不挡内容；悬浮底栏和"已记下"提示条的位置合适。
- [ ] **键盘**：面板里的输入框（体重、份量、遛狗时长、备注）弹出键盘时不被挡住；数字键盘有小数点。
- [ ] **Android 返回**：返回键、返回手势能关掉面板，不会直接退出 App。
- [ ] **日期和时间选择器**：显示语言跟随 App 设置；12/24 小时制跟随系统。
- [ ] **系统语言和地区**：首次打开时，默认语言、单位（公制/英制）、日期顺序是否猜对。
- [ ] **字体**：中文站酷快乐体、悠哉（Paw Hand）和英文 Fredoka 正常显示；首次启动没有明显的字体闪烁；狗狗名字或备注里的生僻字能正常回退到系统字体。

## 性能

- [ ] 中低端 Android 上滚动、打开面板是否流畅。
- [ ] 冷启动时间、安装包大小（完整中文字体会让包变大）。

## 已知问题（Web 上也有，先记着）

- 跨过零点时今天页不会自动刷新。
- 遛狗中的"遛了 N 分钟"不会自己走，要重新打开页面才更新。
